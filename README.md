A complete hands-on implementation of **Unsupervised Machine Learning** algorithms in Python — covering Clustering, Dimensionality Reduction, and Anomaly Detection techniques as part of my AI/ML learning journey.

---

## 📂 Project Structure

```
unsupervised-machine-learning/
│
├── 📓 KMeans.ipynb                    # K-Means with Elbow & Silhouette Score
├── 📓 KMeansForIris.ipynb             # K-Means on Iris Dataset
├── 📓 hierarchical_clustering.ipynb   # Agglomerative Clustering + Dendrogram
├── 📓 DBSCAN.ipynb                    # Density-based Clustering
├── 📓 Clustering_DBSCAN.ipynb         # Extended DBSCAN Experiments
├── 📓 PCA.ipynb                       # Principal Component Analysis
├── 📓 isolation_forest.ipynb          # Anomaly Detection (Isolation Forest + LOF)
│
└── 📊 thyroid_dataset.csv             # Dataset for Anomaly Detection
```

---

## 📚 Topics Covered

### 🔵 Clustering
| Algorithm | Notebook | Highlights |
|---|---|---|
| K-Means | `KMeans.ipynb` | Elbow Method, Silhouette Score, Feature Scaling |
| K-Means on Iris | `KMeansForIris.ipynb` | Cluster visualization on classic dataset |
| Hierarchical | `hierarchical_clustering.ipynb` | Agglomerative approach, Dendrogram |
| DBSCAN | `DBSCAN.ipynb` | Non-linear data, Noise & outlier handling |
| DBSCAN Extended | `Clustering_DBSCAN.ipynb` | Additional clustering experiments |

### 🟣 Dimensionality Reduction
| Algorithm | Notebook | Highlights |
|---|---|---|
| PCA | `PCA.ipynb` | Variance explained, Feature compression |

### 🔴 Anomaly Detection
| Algorithm | Notebook | Highlights |
|---|---|---|
| Isolation Forest + LOF | `isolation_forest.ipynb` | Outlier detection on Thyroid dataset |
