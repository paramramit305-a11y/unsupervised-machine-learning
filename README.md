# unsupervised-machine-learning

A complete collection of Unsupervised ML algorithms implemented in Python as part of my AI/ML learning journey. Covers clustering, dimensionality reduction, and anomaly detection techniques.

---

## 📂 Notebooks

| Notebook | Algorithm | Key Concepts |
|---|---|---|
| `KMeans.ipynb` | K-Means Clustering | Elbow Method, Silhouette Score, Feature Scaling |
| `KMeansForIris.ipynb` | K-Means on Iris Dataset | Cluster visualization on classic dataset |
| `hierarchical_clustering.ipynb` | Hierarchical Clustering | Agglomerative clustering, Dendrogram |
| `DBSCAN.ipynb` | DBSCAN | Density-based clustering, Non-linear data, Noise handling |
| `Clustering_DBSCAN.ipynb` | DBSCAN (Extended) | Extended DBSCAN experiments |
| `PCA.ipynb` | Principal Component Analysis | Dimensionality reduction, Variance explained |
| `isolation_forest.ipynb` | Isolation Forest + LOF | Anomaly detection, Local Outlier Factor |

---

## 📊 Dataset

- **`thyroid_dataset.csv`** — Used for anomaly detection (Isolation Forest / LOF)
